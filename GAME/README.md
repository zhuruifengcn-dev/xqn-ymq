# 苍澜拓土录

> 远古苍澜大朝覆灭，天下大乱，中原朝廷衰弱，西陲万里大地全部成为无主废土、荒疆、弃地。
> 境内无国家、无主权、无现代领土内容。玩家身份：朝廷正式任命【云边镇疆牧守】。
> 所有土地均为无主废土重建——无侵略、无他国战争、无现实领土问题，全程正能量守土开疆。

一个纯前端的无限循环边疆开疆 RPG，零依赖、零构建、零后端。

## 在线游玩

`https://thexqn.net/GAME/`

## 核心机制

| 机制 | 说明 |
|---|---|
| **五维数值** | 民心 / 军政 / 财库 / 教化 / 疆域进度，每回合公示 |
| **永久主线** | 十章循序渐进、不可逆推进，0% → 100% |
| **无限随机任务** | 6 类共 31 个事件，抽过的不再重复 |
| **副本系统** | 7 个副本，随荒疆解锁，可重复挑战 |
| **NPC 智能** | 6 类 NPC 立场固定、态度随行为浮动 |
| **自动存档** | localStorage 自动落盘，可导出/导入 JSON |
| **三结局** | 铁血镇疆 / 盛世牧守 / 万古开疆，按全程行为自动判定 |
| **自由操作** | 20 项自由行动，与主线并行，随时切换 |

## 十章主线

1. 初临荒疆·立足城关（0—15%）
2. 清定乡野·收复平川（15—30%）
3. 打通古道·重开商路（30—45%）
4. 清林固防·取材兴业（45—55%）
5. 临水兴业·安定湖泽（55—65%）
6. 修复古县·重立城治（65—75%）
7. 怀柔北荒·归化部族（75—85%）
8. 平定坞堡·整合豪强（85—92%）
9. 修复雄关·镇守西疆（92—98%）
10. 沧海立港·终定全域（98—100%）

九大荒疆随主线逐章解锁：青川河谷 → 断云古道 → 黑松岭 → 落霞湖泽 →
古残县遗址 → 北荒草甸 → 千石坞堡 → 西峡要塞 → 沧海边陲。对应副本同步开放。

## 目录结构

```
public/GAME/
├── index.html        入口
├── style.css         国风样式（宣纸底 / 墨色字 / 印章红）
├── js/
│   ├── data.js       世界观常量、初始数据、十章主线、NPC 名册、副本、事件池、三结局
│   ├── engine.js     状态机、五维结算、事件抽取（去重）、副本、章节推进、结局判定、存档
│   ├── actions.js    20 项自由行动 + 主线推进 + 随机任务 + 刷副本的具体实现
│   └── ui.js         界面渲染与交互
└── test/
    └── selftest.mjs  引擎端到端自测（23 项断言）
```

## 本地运行

```bash
# 任选其一，在 public 的上级目录启动
node server.js          # 主站（Express）
npx serve public        # 或纯静态服务
```

然后访问 `/GAME/`。
